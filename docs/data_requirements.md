# 재현용 입력 데이터 명세

공개 저장소에는 SNS 원자료와 행 단위 파생 데이터를 포함하지 않습니다. 데이터 의존 기능을 재현하려면 권한을 갖고 별도로 확보한 CSV를 아래 경로에 로컬로 준비하세요. 실제 행이나 값은 저장소에 추가하지 마세요.

## SNS 일별 언급량·감성 원자료

- 경로: `data/raw/sns_daily_mentions_sentiment.csv`
- 형식: UTF-8 CSV, 키워드별·날짜별 한 행
- 식별·날짜 컬럼: `keyword_id`(키워드 식별자), `keyword`(키워드), `date`(날짜; `YYYY-MM-DD` 또는 `YYYY.M.D`)
- 필수 수치 컬럼: `언급량 추이__전체`, `감성__긍정`, `감성__부정`, `감성__중립`
- 채널별 필수 수치 컬럼(각 채널의 언급량): `언급량 추이__커뮤니티`, `언급량 추이__네이버 카페`, `언급량 추이__다음 카페`, `언급량 추이__인스타그램`, `언급량 추이__유튜브`, `언급량 추이__블로그`, `언급량 추이__티스토리`, `언급량 추이__네이버 뉴스`, `언급량 추이__다음 뉴스`, `언급량 추이__언론사 뉴스`
- 값 조건: 언급량·감성 수치는 숫자이며 음수가 없어야 합니다. `keyword_id`와 `date` 조합은 중복될 수 없습니다. 전처리에서 직전 28일 창 계산을 위해 2024-10-04부터 데이터가 필요합니다.
- 생성물: `src/preprocessing/preprocess_sns_data.py`가 `data/processed/sns_keyword_features.csv`를 생성합니다. 이 출력도 원자료의 개별 관측 정보를 담으므로 공개하지 않습니다.

## 기타 입력 데이터

앱과 전체 분석에는 SNS 외에도 `data/raw/theme_stock_daily.csv`, `data/raw/theme_candidates.csv`, `data/raw/opendart/opendart_disclosures.csv`, `data/raw/opendart/opendart_financials.csv`가 사용됩니다. 각 처리 스크립트와 `docs/preprocessing_usage.md`에 정의된 컬럼·취득 조건을 만족하는 파일을 같은 경로에 배치해야 합니다. 공시 API 키는 `.opendart`에 로컬로 두며 커밋하지 않습니다.

## 공개 저장소에서 앱 실행

Streamlit 앱은 입력 파일이 없어도 실행할 수 있습니다. 데이터 소개 화면은 누락된 파일의 로컬 경로와 이 명세를 안내하고, 데이터 기반 분석 화면은 해당 결과 파일이 없으면 결과를 표시하지 않습니다. 분석을 재현하려면 필요한 원자료를 로컬에 준비한 뒤 전처리·분석 명령을 실행하세요.
