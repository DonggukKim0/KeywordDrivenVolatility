# 커밋 메시지 규칙

| 타입 | 사용 목적 |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 오류 수정 |
| `docs` | README, 프로젝트 문서, 발표 자료 수정 |
| `data` | 데이터 추가·갱신 및 데이터 구성 변경 |
| `refactor` | 동작을 유지하면서 코드 구조 개선 |
| `test` | 테스트 추가·수정 |
| `chore` | 폴더 구조, 의존성, 개발 환경 설정 등 관리 작업 |

`data`는 데이터 작업을 구분하기 위해 이 프로젝트에서 사용하는 타입입니다.

### 작성 예시

```text
chore: 초기 프로젝트 폴더 구조 구성
docs: 프로젝트 디렉토리 구조 설명 추가
data: 키워드별 주가 원본 데이터 추가
feat: 뉴스 키워드 전처리 기능 추가
feat: 변동성 분석 대시보드 추가
fix: 주가 데이터 날짜 정렬 오류 수정
```

### 명령어 예시

```bash
# 제목만 작성
git commit -m "docs: README 커밋 메시지 규칙 추가"

# 본문도 작성 (두 번째 -m 앞에 빈 줄이 자동으로 들어갑니다)
git commit -m "fix: 주가 데이터 날짜 정렬 오류 수정" \
  -m "날짜가 문자열로 정렬되어 시계열 순서가 잘못되는 문제를 해결했습니다."
```
